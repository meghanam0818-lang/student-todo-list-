# Student To-Do List 📝

A simple, responsive task manager for students built with HTML, CSS, and JavaScript.

## Features
- Add tasks and assignments
- Mark tasks as completed
- Delete tasks
- Automatically saves tasks in your browser using local storage
- Responsive design for mobile and desktop

## How to run
1. Extract the ZIP file.
2. Open `index.html` in a web browser.
